# Nodsy_Jointure

**A full-body physics interaction system inspired by Boneworks/Bonelab.**

Nodsy_Jointure brings physically simulated bodies, joints, and grabbable objects to life — no animation tricks, no fake IK, just real physics driving every interaction. Every limb, joint, and object behaves according to actual physical constraints, creating emergent, unpredictable, and satisfying interactions.

## Features

- **Articulated Ragdoll System** — Fully simulated skeletons with realistic joint constraints
- **Physics-Based Grabbing** — Grip, throw, and manipulate objects using real forces, not scripted animations
- **Dynamic Joint Networks** — Configurable joints (hinge, ball, fixed) that respond naturally to force and collision
- **Full-Body Interaction** — Push, pull, climb, and collide with the world using your entire simulated body
- **Real-Time Constraint Solving** — Stable, performant physics even under complex multi-body interactions

## Why Nodsy_Jointure?

Most physics interaction systems fake it — canned animations, snapped-in-place grabs, invisible colliders. Nodsy_Jointure aims for the opposite: a world where every interaction emerges from real joint and rigid-body simulation, giving players (and developers) the same chaotic, physical playground that made Boneworks and Bonelab so memorable.
